# dsh-token-pill

极简、直观的 DeepSeek Harness 会话与全局 Token 用量统计插件。

## 特色

- **轻量无感常驻**：在底部输入框工具栏与会话顶部导航常驻一枚小胶囊（如 `⚡ 38.2k · 缓 96%`，空会话或主页显示低调的 `⚡ 0`，顶部栏空会话时自动隐藏）。
- **会话级实时明细**：实时统计当前会话的补全输出量、未缓存输入量、缓存读取量与命中率、最近一轮增量消耗、会话轮次与模型运行耗时。
- **全局历史聚合分析**：内置全局汇总与趋势分析：
  - 支持 **今日** / **近 7 天** / **近 30 天** 分段切换。
  - **构成条**：输出 / 未缓存输入 / 缓存读取三段占比一目了然。
  - **关键指标**：总消耗、日均消耗、缓存命中率、活跃天数、模型交互次数。
  - **每日走势条形图**：按日比例条 + 总量 + 命中率，今天自动高亮。
  - **活跃会话 TOP 5**：带比例条的排行榜，直观看出谁在烧 Token。
- **纯粹 Token 统计**：不搞复杂的计费折算、美元汇率与价格表，专注纯粹真实的 Token 用量与缓存效率。
- **一键复制报告**：点击面板底部「复制报告」，把当前视图（含每日走势与会话排行）复制为纯文本。

## 数据来源

- 当前会话：会话 projection 缓存中的 `tokenUsage` / `sessionStats`，随对话实时刷新。
- 全局历史：扫描 `~/.dsh/sessions` 下的会话日志，按**本地时区**把每条 assistant 消息的 usage 汇总到日期；首次请求解析全部日志，之后只重新解析有变化的文件。
- 兼容兜底：若存在 `~/.dsh/storages/cost-meter/ledger.json` 的每日账本，则按“同一天取总量更完整者”合并；近 48 小时内活跃会话的 projection 数据用于补上尚未落盘的增量。
- 同一会话迁移后可能同时存在 `session.jsonl.zstd` 与 `session.v4.jsonl.zstd`，会按新版优先去重，避免重复累计。

## 注意

全局统计由插件后台路由 `/__dsh-token-pill/stats` 提供。插件新增的后台路由只在客户端启动时注册，**首次安装或升级后需完全退出 DeepSeek Harness 再重新打开**（仅 Ctrl+R 只重载界面）。
