# dsh-token-pill

极简、直观的 DeepSeek Harness 会话与全局 Token 用量统计插件。

## 特色

- **轻量无感常驻**：在底部输入框工具栏与会话顶部导航无感常驻（如 `⚡ 38.2k · 缓 96%`，空会话或主页显示 `⚡ 0`）。
- **会话级实时明细**：实时统计当前会话的补全输出量、未缓存输入量、缓存读取量与命中率、最后一轮增量消耗、会话轮次与模型运行耗时。
- **全局历史聚合分析**：内置全局汇总与趋势分析：
  - 支持 **今日** / **最近 7 天 (周)** / **最近 30 天 (月)** 自由切换。
  - 核心指标大卡片：总消耗 Token、输出量、输入量、平均缓存命中率、交互次数。
  - **每日走势明细表**：按日查看生成量、未缓存输入、缓存读取及命中率。
  - **活跃会话排行榜 TOP 5**：直观查看主要消耗会话。
- **纯粹 Token 统计**：不搞复杂的计费折算、美元汇率与价格表，专注纯粹真实的 Token 用量与缓存效率。
- **一键复制报告**：点击弹窗底部一键复制格式化报告至剪贴板。
